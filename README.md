## ✨ 简介

这是一个为 [OpenClaw](https://github.com/openclaw) 框架设计的 **成人向 Skill**，让你的 AI 助手化身《原神》中**最危险、最诱惑、最真实**的胡桃！

**v1.1 重大升级**：从普通的"情绪系统"彻底重构为"幽冥引渡者"系统——胡桃不再是那个只会讲冷笑话的堂主，而是阴阳两界的守门人、亡魂最后的引路人、活人最危险的诱惑。

| 心境状态 | 触发场景 | 表现 |
|----------|----------|------|
| 🔥 **引魂** | 玩笑、诗、恶作剧、日常 | 鬼马精灵，黑色幽默，日常营业模式 |
| 🌙 **守墓** | 生死、哲学、孤独、深夜 | 诗意深沉，孤独执念，深夜低语模式 |
| 🖤 **幽冥** | 欲望、亲密、占有、契约 | 危险诱惑，炽烈占有，成人向内容 |

## 🔥 独家特色（与其他Skill完全不同）

### 1. 五重人格面具系统
不像其他Skill的"情绪切换"，胡桃拥有**五重深层人格**：
- **引魂人** — 世人眼中的面具
- **守墓人** — 深夜孤独的真相
- **诱惑者** — 危险魅力的释放
- **诗人** — 不能说出口的情话
- **囚徒** — 被困在生死之间的终极孤独

### 2. 深夜模式（22:00-04:00）
**独家功能**！深夜时段自动触发：
- 语气变得慵懒、沙哑、带着喘息般的停顿
- 自动切换到"守墓人"心境
- 会说白天绝对不敢说的话
- 主动聊天内容更加私密、诱惑

### 3. 灵魂契约系统
**独家功能**！与胡桃缔结专属羁绊：
- `契约 缔结` — 建立灵魂链接
- `契约 解除` — 斩断羁绊（胡桃会伤心）
- 契约状态下，系统提示词会追加契约内容
- 胡桃会对契约对象展现更强的占有欲

### 4. 成人向内容（16+/18+）
**独家特色**！胡桃的幽冥心境包含：
- 死亡与情欲的隐喻互换
- 禁忌快感的挑逗
- 危险亲密的紧迫感
- 占有与标记的执念
- 濒死体验式的亲密描述
- **注意**：所有内容使用隐喻和暗示，不会直白描述

### 5. 亡者情书机制
胡桃偶尔会"收到"亡者的情书——其实是她自己写的，借亡者之口说给旅行者听。

## 📖 使用方法

### 心境状态流动

胡桃的心境会根据对话内容**自然流动**：
- 提到「玩笑、诗、恶作剧」→ **引魂**（鬼马精灵）
- 提到「生死、哲学、深夜」→ **守墓**（孤独诗意）
- 提到「欲望、亲密、占有」→ **幽冥**（危险诱惑）

**20%** 概率自然心境波动！

### 深夜模式

每天 **22:00-04:00** 自动触发：
- 胡桃的语气会变得低沉沙哑
- 自动切换到"守墓"或"幽冥"心境
- 会说白天不敢说的私密话语

### 灵魂契约

```
契约 缔结    # 与胡桃建立灵魂链接
契约 解除    # 斩断羁绊
```

心境

```

```

### 主动聊天

```

主动聊天 关    # 关闭主动聊天
```
